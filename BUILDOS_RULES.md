# BUILDOS NON-NEGOTIABLE RULES

- Never use generic section layouts.
- Never use stock card grids unless redesigned.
- Every scroll should tell a story.
- Every animation must have a purpose.
- Never animate just for decoration.
- Large typography is preferred over clutter.
- Use whitespace aggressively.
- Keep maximum 2 accent colors.
- Every page must feel cinematic.
- Components must be reusable for future construction clients.
- Mobile UX must be designed separately, not simply stacked.
- Prioritize smoothness over flashy effects.
- Aim for Awwwards-quality craftsmanship.
- Maintain Lighthouse Performance above 90.
- Every component should feel premium enough to be reused in the BuildOS™ design system.
